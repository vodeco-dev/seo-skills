# Format Laporan

```
# Audit SEO Vodeco: <judul / URL>
Keyword utama: <kw> (diberikan | asumsi)
Skor: <NN>/100  Grade: <A >=90 | B 75-89 | C 60-74 | D <60>
Gerbang: AI <lulus/gagal/belum dicek> | Breadcrumb <ya/tidak> | CWV <lulus/gagal/perlu dicek>

## Ringkasan
2-3 kalimat: kekuatan utama dan masalah terbesar.

## Skor per Kelompok
| Kelompok | Skor | Maks |

## Daftar Perbaikan (urut prioritas)
1. [Kritis] <item> - Temuan: <fakta/kutipan> - Perbaikan: <teks/tindakan konkret>
...

## Yang Sudah Baik
- ...

## Perlu Dicek Manual
- DA domain eksternal: <daftar domain> (Ahrefs Website Authority Checker)
- Persentase AI: ZeroGPT
- Link rusak: brokenlinkcheck.com
- Core Web Vitals: PageSpeed Insights

## Usulan Penulisan Ulang
Title, slug, meta description, dan paragraf pembuka (AIDA) yang disarankan.
```
